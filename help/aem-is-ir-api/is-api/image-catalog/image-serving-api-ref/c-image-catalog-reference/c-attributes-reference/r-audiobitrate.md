# VelocidadBitsAudio{#audiobitrate}

Velocidad de bits de audio. Valor largo que representa la velocidad de bits de audio del recurso de vídeo.

Utilizado por `req=set` y `req=mbrSet`solicitudes para exportar datos de velocidad de bits.

Solo se aplica al catálogo de contenido estático.

## Propiedades {#section-76731467b23240ac89b0767491c6020b}

Valor entero (bps)

## Predeterminado {#section-dba669ea75354671bbdb3b520e2f6911}

Ninguno.
