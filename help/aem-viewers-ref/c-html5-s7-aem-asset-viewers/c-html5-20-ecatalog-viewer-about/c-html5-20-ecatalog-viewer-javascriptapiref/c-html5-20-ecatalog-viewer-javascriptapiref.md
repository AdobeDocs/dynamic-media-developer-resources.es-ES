# Referencia de la API de JavaScript para el visor de catálogos electrónicos{#javascript-api-reference-for-ecatalog-viewer}

La clase principal del visor de catálogos electrónicos es eCatalogViewer. Se declara en el área de nombres de s7viewers. Esta API de JavaScript cubre el constructor, los métodos y las llamadas de retorno de esta clase en particular.

En todos los ejemplos siguientes, `<instance>` significa el nombre real del objeto de visor de JavaScript que se crea a partir de la clase `s7viewers.eCatalogViewer`.
